# Mission-1

## Task 1.1 — Tracing an Activity Using IPOS (Typing and Saving a Note)
| Stage | What happens in my example? | Hardware / Component |
| :--- | :--- | :--- |
| **Input** | I press keys on my keyboard to type out notes. | Keyboard |
| **Processing** | The processor turns my keystrokes into text characters and holds the open note in memory. | CPU and RAM |
| **Output** | The words show up on my screen as I type. | Monitor / Screen |
| **Storage** | When I hit save, the file is stored permanently so it stays there even after I turn off my computer. | SSD |

## Task 1.2 — Identifying Hardware and Software
| Item / Software Name | Hardware or Software? | Software Type | Purpose |
| :--- | :--- | :--- | :--- |
| Keyboard | Hardware | Not applicable | Used to type text and enter commands. |
| Trackpad / Mouse | Hardware | Not applicable | Moves the pointer and selects items on the screen. |
| Screen / Display | Hardware | Not applicable | Shows visual output from the computer. |
| SSD | Hardware | Not applicable | Saves files, apps, and the operating system permanently. |
| macOS / Windows | Software | Operating system software | Runs the computer and manages hardware and memory. |
| Web Browser (Chrome / Safari) | Software | Application software | Lets me browse websites and search online. |
| VS Code | Software | Application software[cite: 4] | Helps me write and edit code and README files. |
| Activity Monitor / Task Manager | Software | Utility software | Helps check system health, CPU usage, and memory. |
