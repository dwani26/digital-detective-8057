## 4. My understanding
Every computer works by following the IPOS cycle: it takes in data through input devices, processes it using the CPU and memory, shows the result through output devices, and saves it in storage for later. Hardware is the physical equipment I can touch, while software gives the instructions—whether it is the operating system running the machine, apps I use daily, or utilities keeping things running smoothly.
