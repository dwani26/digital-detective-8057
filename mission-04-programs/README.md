## 4. What I Understood
I learned that computers cannot directly execute human-readable source code—it must first be translated into machine instructions:
* **Compiler:** Translates the entire source code into machine code *before* execution, typically generating a separate standalone executable file.
* **Interpreter:** Reads, translates, and executes the code line-by-line *during* runtime without producing a separate compiled output file.

Both achieve the same goal of running programs, just through different execution workflows.
