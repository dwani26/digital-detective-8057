# Mission 2 - Terminal and File Management

## 1. Task / objective
Practise basic Terminal commands for navigating folders and managing files, safely edit text files, understand command flags and pipes, and explore package managers.

## 2. Work completed
- **Task 2.1:** Practiced basic Terminal commands and recorded what each one did.
- **Task 2.2:** Made a practice folder, added two lines of text to a file without deleting the first line, and created a backup copy.
- **Task 2.3:** Tried `ls` and `ls -lah` and  also used a pipe to show just a few lines.
- **Task 2.4:** Checked if Homebrew was installed and learned why package managers are used for.

## 3. Commands / tools used
- `pwd`, `ls`, `cd`: Used them to check my current location and to switch between folders.
- `mkdir`, `touch`, `cp`, `mv`, `cat`: Used these to create, copy, rename and read files.
- `echo`,`>`, `>>` : Used these to add text into files and to add more text without deleting the old content
- `ls -lah` and `|` (pipe): Used to learn extra file details and to send output from one command to another.
- `brew --version`: Used this to check the installed Homebrew version.
- `git add`, `git commit`, `git push`: Used these to save the changes and push them to GitHub.

## 4. My understanding
I learned that the Terminal can be used to do a lot of things that we normally do using folders and files on the screen. I also understood why > and >> are different, since one replaces the old content while the other adds to it. Flags help show extra information and pipes are useful when I don't want the full output of a command. I also learned that Homebrew makes it easier to install and manage software on macOS.
