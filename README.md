## How to Run the Number Converter

I created a simple Python program in Mission 5 that converts a decimal number into binary and hexadecimal.

To run the program, open the Terminal in the main project folder and enter:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

Enter a decimal number when the program asks for it. It will display the binary and hexadecimal values.

**Example:**

If I enter `25`, the output will be:

- Binary: `11001`
- Hexadecimal: `19`
